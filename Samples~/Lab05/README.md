# Lab 05 — Optymalizacja modeli CAD

Ten folder jest próbką pakietu **WiRR Course Toolkit** przeznaczoną dla Laboratorium 5.

Laboratorium korzysta z bazowego URP; panel nie instaluje dodatkowego pakietu laboratoryjnego.

## Zalecana kolejność

1. Otwórz `WiRR → Course Toolkit`.
2. Wybierz Lab 05.
3. Zainstaluj / napraw zależności.
4. Zaimportuj oficjalne próbki Unity, jeżeli są wymagane.
5. Użyj `Create / repair base scene`.
6. Uruchom `Validate scene`.
7. Pracuj zgodnie z instrukcją PDF laboratorium.
8. Do sprawozdania użyj `Create / open report template`.

`report-template.md` jest synchronizowany z aktualnym szablonem instrukcji laboratorium.
